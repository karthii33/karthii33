### 📌 Featured Projects

#### 🏢 [Stromex](https://github.com/karthii33/Stromex) — Company Website + CRM
Full-stack site for **StromexAI Tech Solutions LLP** with a built-in CRM behind a login: dashboard with charts, **leads, customers, support tickets** and contact-form inbox.
`React 19` `Vite` `React Router` `Recharts` `Express 5` `Prisma` `PostgreSQL` `JWT` `bcrypt` `EmailJS` · deployed on Vercel + Render

#### 🎙️ [LiveKit Chimtu](https://github.com/karthii33/Livekit_chimtu) — Real-time AI Voice Assistant
"Chimtu" — a sarcastic butler-style personal assistant you can **talk to live**, with camera input. Runs on Google's Gemini realtime model over LiveKit with background noise cancellation.
`Python` `LiveKit Agents` `Gemini Realtime` `WebRTC` `Noise Cancellation`

#### 🗳️ [Student Voting System](https://github.com/karthii33/Student-voting-project) — Secure Online Elections
Election platform with student login + **Google OAuth**, **Fernet-encrypted votes**, live results and an admin panel for managing candidates.
`Flask` `MongoDB` `Google OAuth` `cryptography` `bcrypt`

#### 👓 [EyeKarthii Store](https://github.com/karthii33/EyeKarthii) — Eyewear E-commerce
Online eyewear shop with sign-up/login, product catalogue, cart, buy-now, **cash-on-delivery checkout** and order history.
`Flask` `MongoDB` `Flask-Bcrypt` `Jinja2`

#### 📝 [NexTask](https://github.com/karthii33/To_Do_List) — Smart To-Do for Students
Task manager with priorities, due dates, done/undo, user accounts, profile pictures and dark mode.
`Flask` `Flask-Login` `MongoDB` `TailwindCSS`
